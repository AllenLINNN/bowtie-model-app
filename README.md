# Bowtie App Prototype

**線上展示網址：[https://allenlinnn.github.io/](https://allenlinnn.github.io/)**

這是一個基於 React + TypeScript 打造的「純前端離線版」Bowtie 風險模型編輯器。

## 🎯 核心功能

*   **🔒 本機離線安全 (Local-First)**：所有專案與庫存資料皆自動儲存於您的瀏覽器 (`IndexedDB`)，絕不上傳雲端，確保機密資訊不外洩。
*   **🖱️ 現代化編輯畫布**：
    *   **快速建構**：從左側面板拖曳節點即可建立關聯。支援**雙擊節點**快速修改名稱。
    *   **自動排版**：提供一鍵「自動排版」功能，瞬間將凌亂的節點整齊排列。
    *   **寬闊視野**：頂端工具列可隨時**摺疊/展開左右側邊欄**，最大化繪圖空間。
*   **📚 全域專屬資料庫 (Library)**：
    *   將常用的節點（含編號、屏障類型、效力）點擊「儲存」即可加入全域資料庫。
    *   在任何新專案中，皆可直接從左側「專屬資料庫」拖曳公版節點，自動帶入所有設定與編號。
*   **🔢 智慧自動編號**：拖曳新範本會給予預覽編號（如 `H-001`），存入資料庫時正式鎖定並推進計數器。
*   **📂 專案總覽 (Dashboard)**：
    *   卡片式管理介面，自動統計各專案的**節點分佈數量**，並標示專案完整度。
    *   內建「資源回收筒」機制，誤刪專案可隨時復原。
*   **📦 無縫協作與輸出**：
    *   **工作區匯出/匯入**：一鍵將整個系統資料打包為 JSON 檔，傳送給同事匯入即可無縫接軌。
    *   **高畫質輸出**：根據節點範圍自動裁切，支援輸出超高解析度 **透明去背 PNG** 或 **PDF 文件**。
