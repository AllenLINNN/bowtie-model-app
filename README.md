# Bowtie App Prototype

**網址：[https://allenlinnn.github.io/bowtie-model-app/](https://allenlinnn.github.io/bowtie-model-app/)**

## 核心功能

*   **Local-First**：所有專案與庫存資料皆自動儲存於瀏覽器 (`IndexedDB`)。
*   **編輯畫布**：從左側面板拖曳節點即可建立關聯。支援**雙擊節點**快速修改名稱。
*   **全域專屬資料庫**：
    *   將常用的節點（含編號、屏障類型、效力）點擊「儲存」即可加入資料庫。
    *   在任何新專案中，皆可直接從左側「專屬資料庫」拖曳公版節點，自動帶入所有設定與編號。
*   **自動編號**：拖曳新範本會給予預覽編號（如 `H-001`）。
*   **專案總覽**：
    *   卡片式管理介面，自動統計各專案的**節點分佈數量**，並標示專案完整度。
    *   內建「資源回收筒」機制，誤刪專案可隨時復原。
*   **協作與輸出**：
    *   **工作區匯出/匯入**：一鍵將整個系統資料打包為 JSON 檔，傳送給其他人匯入即可匯入檢視與編輯。
    *   **高畫質輸出**：根據節點範圍自動裁切，支援輸出 **透明去背 PNG** 或 **PDF 文件**。
