# Bowtie App Prototype

這是一個基於 React + TypeScript 打造的「純前端離線版」Bowtie 風險模型編輯器 Prototype。

## 專案特色

*   **完全離線 (Local-First)**：所有的操作、模型與庫存資料皆自動且即時儲存於您個人瀏覽器的 `IndexedDB` 之中。沒有後端伺服器，資料絕不上雲端，確保機密資訊安全。
*   **視覺化拖曳編輯 (React Flow)**：提供直覺的拖曳畫布，並內建嚴格的 Bowtie 邏輯驗證（例如：Threat 只能連接到 Preventive Barrier 或 Top Event）。
*   **全域資料庫 (Global Library)**：可以將常用的 Hazard、Top Event、Barrier 等節點存入共用資料庫，並在不同專案中重複拖曳使用。
*   **自動編號系統**：從範本拖曳新節點時，系統會依據節點類型自動賦予專屬編號（如 `H-001`, `PB-002`）。編號在節點被「Save」至 Library 時正式鎖定並推進計數器。
*   **完整匯出/匯入機制**：支援將整個工作區（包含所有專案與 Library）匯出為單一 `.json` 檔案，方便備份或與同事交換模型。同時支援將畫布匯出為 PNG 圖片或 PDF 文件。

## 🚀 如何啟動專案 (開發者模式)

如果您是開發者，並需要在本機運行原始碼或繼續開發，請遵循以下步驟：

### 系統需求
*   [Node.js](https://nodejs.org/) (建議安裝 LTS 版本)

### 啟動步驟
1. 打開終端機 (命令提示字元 `cmd` 或 Mac Terminal)。
2. 進入 `frontend` 資料夾：
   ```bash
   cd frontend
   ```
3. 安裝所有必要的依賴套件：
   ```bash
   npm install
   ```
4. 啟動本機開發伺服器：
   ```bash
   npm run dev
   ```
5. 開啟瀏覽器並前往終端機提示的網址 (通常是 `http://localhost:5173`) 即可開始使用。

## 📦 如何分享給同事 (免安裝單一檔案版)

為了讓您的同事能最輕鬆地使用這個 Prototype，我們設定了單一檔案打包機制。您的同事**不需要安裝 Node.js**，也不需要懂任何指令。

### 打包步驟 (由您執行)
1. 確保您在 `frontend` 資料夾下，並且已經執行過 `npm install`。
2. 執行打包指令：
   ```bash
   npm run build
   ```
3. 執行完畢後，進入 `frontend/dist/` 資料夾。
4. 您會找到一個名為 **`index.html`** 的檔案。這就是包含了所有程式碼、樣式與圖示的最終完成品。
5. (可選) 您可以將這個檔案重新命名為更容易理解的名稱，例如 `Bowtie-App.html`。

### 同事如何使用
1. 您可以透過 Email、Teams、USB 等任何方式將這個 `.html` 檔案傳送給同事。
2. 同事收到後，只需**對著檔案點擊兩下**（使用 Chrome 或 Edge 瀏覽器開啟）。
3. 網頁會立即載入，同事即可直接開始使用所有拖曳、畫圖、存檔的功能（資料同樣會離線儲存在他自己的瀏覽器中）。

## 📖 核心功能操作指南

### 匯入 (Import) 工作區 JSON
1. 點擊畫面上方導覽列右側的 **「Import」** 按鈕（向下箭頭圖示）。
2. 選取您或同事匯出的 `.json` 檔案。
3. 系統會自動讀取並覆蓋當前資料，隨後將您導向回 Dashboard (專案總覽面板)。
4. 您現在可以點擊任何匯入的專案卡片進入畫布，左側的 Library 也會同步載入匯入的公用節點。

### 編輯專案名稱
在專案畫布介面中，**點擊頂端列正中央的專案名稱**即可進入編輯模式。修改完成後按下 `Enter` 鍵或點擊旁邊空白處即可儲存。

### 儲存節點至全域資料庫 (Save to Library)
1. 在畫布上點擊任何一個您想重複使用的節點。
2. 右側會滑出屬性面板 (Properties Panel)，您可以編輯它的 Name、Code (編號)、Description 等資訊。
3. 點擊面板右上角的 **「Save」** 按鈕。
4. 該節點即被永久存入左側的 **Library** 頁籤中。同時，該節點的自動編號也會被正式鎖定。

### 匯出圖表 (Export PNG / PDF)
在畫布介面中，點擊右上角的 **「PNG」** 或 **「PDF」** 按鈕，系統會自動擷取當前畫布的內容並下載檔案。（注意：只有在進入特定專案畫布時，才會顯示這兩個按鈕）。
